# Чек-лист адаптивной вёрстки

Пройдите по списку перед тем, как считать страницу готовой.

## Ширина

- [ ] На 320px нет горизонтальной прокрутки
- [ ] Ни одного `width` в пикселях там, где годится `max-width: 100%`
- [ ] Таблицы и блоки кода прокручиваются внутри себя, а не тянут страницу
- [ ] Длинные слова и ссылки не выпирают — `overflow-wrap: anywhere`

## Точки переключения

- [ ] Брейкпоинты поставлены там, где ЛОМАЕТСЯ макет, а не по моделям телефонов
- [ ] Сначала мобильная вёрстка, потом `min-width` — так меньше переопределений
- [ ] Между брейкпоинтами тоже проверено: 900px ломается чаще, чем 375px

## Прикосновение

- [ ] Кнопки и ссылки не меньше 44×44px
- [ ] Между соседними целями есть зазор — иначе промахи
- [ ] Ничего важного не спрятано только под `:hover` — на тач-экране его нет

## Текст

- [ ] Базовый размер не меньше 16px: меньше — и Safari сам зумит страницу при фокусе в поле
- [ ] Строка 45–75 символов, не шире
- [ ] Межстрочный интервал в основном тексте не меньше 1.5

## Изображения

- [ ] У `<img>` заданы `width` и `height` — иначе макет прыгает при загрузке
- [ ] Тяжёлые картинки ниже первого экрана — `loading="lazy"`

## Последнее

- [ ] Проверено при 200% масштаба браузера
- [ ] Проверено с `prefers-reduced-motion: reduce`
- [ ] Проверено в альбомной ориентации телефона
