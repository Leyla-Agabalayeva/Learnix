# Learnix

Система управления обучением: каталог курсов, прохождение уроков, тесты
с автоматической проверкой и сертификаты. Три роли, три языка интерфейса,
многоязычное содержимое курсов на уровне базы данных.

Итоговый проект. Бэкенд — ASP.NET Core 8 (Clean Architecture, 7 проектов),
фронтенд — vanilla JavaScript без фреймворка.

## Что умеет

### Студент
Ищет курсы в каталоге с фильтрами и сортировкой, откладывает их в избранное,
записывается, проходит уроки с видео и материалами, сдаёт тесты, следит за
прогрессом и получает сертификат с проверяемым номером.

### Преподаватель
При регистрации указывает профессиональный профиль (должность, область
экспертизы, стаж, о себе, а также по желанию образование, место работы и
ссылку на LinkedIn или сайт): он проверяется на сервере и позже
редактируется. Создаёт курсы, собирает программу из модулей и уроков перетаскиванием,
заполняет содержимое сразу на трёх языках (курсы, модули, уроки, а теперь
и тесты), публикует, видит аналитику по своим курсам, список студентов
и отзывы.

### Любой человек
Проверяет подлинность сертификата по номеру — **без регистрации**. Это
единственный эндпоинт системы, открытый без авторизации.

### Что стоит отметить отдельно
- **Загрузка аватара, а не просто ссылка.** Фото профиля можно снять
  на камеру устройства или загрузить с диска (`POST /api/auth/me/avatar`) —
  единственное место в приложении с настоящей загрузкой файла; всё остальное
  (обложки курсов, материалы уроков) по-прежнему задаётся ссылкой осознанно
  (см. [Что осталось за рамками](#что-осталось-за-рамками)).
- **Восстановление пароля по email.** «Забыли пароль?» отправляет настоящее
  письмо через Gmail SMTP с одноразовой ссылкой для сброса.
- **Тёмная тема.** По умолчанию следует системной настройке, есть ручной
  переключатель, который запоминается в браузере.

## Архитектура

```
LMSFinal.Domain          сущности, перечисления, интерфейсы репозиториев
LMSFinal.Contracts       DTO — единственное, что видит внешний мир
LMSFinal.Application     сервисы, бизнес-правила, валидаторы, маппинг
LMSFinal.Persistence     EF Core: DbContext, конфигурации, репозитории, seed
LMSFinal.Infrastructure  внешние сервисы: JWT, почта, генерация PDF
LMSFinal.WebApi          контроллеры, middleware, Swagger, wwwroot
LMSFinal.Tests           xUnit + Moq
```

Зависимости направлены внутрь: `WebApi → Application → Domain`.
`Domain` не знает ни о ком. `Persistence` реализует интерфейсы, объявленные
в `Domain`, — поэтому `Application` работает с базой, ничего не зная про EF Core.

**В цифрах:** 25 сущностей, 25 конфигураций Fluent API, 14 сервисов,
19 валидаторов, 16 контроллеров, 65 эндпоинтов, 115 тестов, ~22 400 строк C#
и ~9 500 строк JavaScript.

### Сквозные механизмы

- **`GlobalExceptionMiddleware`** — единая обработка ошибок. Сервисы просто
  бросают `NotFoundException` / `ForbiddenAccessException` / `ConflictException`,
  а `try/catch` в контроллерах не нужен вовсе.
- **`ApiResponse<T>`** — единый формат ответа: `{ data, success, message, errors }`.
- **Repository + Unit of Work** — сохранение одной транзакцией.
- **`TranslationResolver`** — выбор перевода с запасным вариантом:
  запрошенный язык → AZ → EN → любой имеющийся. Используется для курсов,
  модулей, уроков — а теперь и для тестов, вопросов и вариантов ответа.
- **`IEmailSender`** — тонкая абстракция над SMTP: `AuthService` отправляет
  письма, не зная и не заботясь о том, как именно они доставляются.

## Схема базы данных

![ERD](docs/erd.svg)

На схеме — собственные таблицы приложения плюс `AspNetUsers` и `AspNetRoles`
из Identity (остальные служебные таблицы Identity не показаны, чтобы не
засорять картинку). Переводы тестов (`QuizTranslations`, `QuestionTranslations`,
`AnswerTranslations`) появились уже после того, как эта диаграмма была
нарисована — по форме они идентичны `LessonTranslations`, просто на один
уровень глубже.

Ключевые решения:

**Содержимое курсов, уроков и теперь тестов переводится в базе, а не в
интерфейсе.** Название и текст урока лежат в `LessonTranslations` по строке
на язык, и API отдаёт нужный по параметру `?lang=`. Тесты устроены точно так
же (`QuizTranslations` → `QuestionTranslations` → `AnswerTranslations`) —
добавлено позже, когда изначально англоязычная схема тестов потребовала
того же подхода, что и всё остальное. Это отдельный механизм от перевода
интерфейса — их нельзя путать: интерфейс переводится из `/locales/*.json`
на клиенте.

**Удаление настроено осознанно, а не по умолчанию.** Модуль удаляется вместе
с уроками (`Cascade`) — без курса они не имеют смысла. Курс со студентами
не удаляется вовсе (`Restrict`): вместе с ним исчезли бы прогресс, оценки
и выданные сертификаты.

**Результат теста восстановим.** `QuizAttempts` хранит не только балл, но и
каждый выбранный вариант (`QuizAttemptAnswerSelections`). Балл можно пересчитать
из сохранённых ответов и проверить — он не «просто число в колонке».

## Как запустить

### Нужно
- .NET SDK 8.0
- SQL Server (подойдёт LocalDB или Express)

### Шаги

**1. Настройки.** Скопируйте образец и заполните:

```bash
cd LMSFinal.WebApi
copy appsettings.Development.example.json appsettings.Development.json
```

Заполните строку подключения, ключ JWT (не короче 32 символов) и пароли.
Секция `Email` необязательна — оставьте `SenderEmail`/`SenderPassword`
пустыми, и приложение прекрасно запустится; «Забыли пароль?» просто
залогирует неудачную отправку вместо реального письма (см.
[восстановление пароля](#что-стоит-отметить-отдельно)).

> `appsettings.Development.json` исключён из git — в нём секреты.
> В репозиторий попадает только образец с пустыми значениями.

**2. База.** Миграция применяется при первом запуске автоматически.
Вручную — так:

```bash
dotnet ef database update --project LMSFinal.Persistence --startup-project LMSFinal.WebApi
```

**3. Запуск.**

```bash
dotnet run --project LMSFinal.WebApi
```

Приложение поднимется на `http://localhost:5204`.
Фронтенд отдаётся тем же приложением из `wwwroot` — отдельный сервер не нужен,
и CORS поэтому не настраивается вовсе.

При первом запуске база наполняется демо-данными: 10 курсов, 23 модуля,
51 урок, 13 тестов, 9 студентов с реальным прогрессом и сертификатами.
Отключается флагом `Seed.EnableDemoData`.

## Как запустить через Docker

Весь стек (API + SQL Server) можно поднять и в контейнерах — не нужен ни
локальный .NET SDK, ни установленный SQL Server, только Docker Desktop.

**1. Секреты.** Скопируйте образец и заполните:

```bash
copy .env.example .env
```

Впишите пароль для SQL Server, ключ JWT, пароли для seed-админа/демо-аккаунтов
и (по желанию) данные Gmail SMTP для писем восстановления пароля — нужен
**пароль приложения** Gmail, а не обычный пароль от аккаунта (Google выдаёт
его только после включения двухэтапной аутентификации, на странице
[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)).
`.env` исключён из git, в репозиторий попадает только `.env.example`.

**2. Сборка и запуск.**

```bash
docker compose up --build -d
```

Собирается образ API, поднимается SQL Server, приложение ждёт, пока он
станет healthy, и запускается само — применяет миграции и наполняет
свежую базу демо-данными автоматически. Приложение доступно на
`http://localhost:5204`, так же как и при локальном запуске.

**3. Остановить / перезапустить.**

```bash
docker compose stop      # контейнеры и данные остаются, просто останавливаются
docker compose up -d     # запускает снова, пересборка не нужна
docker compose down      # удаляет контейнеры (данные сохраняются — см. ниже)
docker compose down -v   # удаляет контейнеры И том с базой данных
```

Два именованных тома переживают пересборку: `sql-data` (база данных) и
`avatar-uploads` (фото, загруженные через страницу профиля). Стирает их
только `down -v` — обычный `down` или пересборка данные не трогают.

## API

Swagger — на `/swagger`. Эндпоинты сгруппированы по пользовательским
сценариям, у каждого описание, коды ответов и примеры тел запроса.

Кратко по группам:

| Группа | Что делает |
|---|---|
| `/api/auth` | регистрация, вход, профиль, загрузка аватара, восстановление пароля |
| `/api/courses` | каталог с фильтрами, карточка курса, CRUD для преподавателя |
| `/api/modules`, `/api/lessons` | программа курса, изменение порядка |
| `/api/enrollments` | запись на курс, мои курсы |
| `/api/progress` | отметка урока, процент прохождения, «продолжить» |
| `/api/quizzes` | тесты, проверка ответов **на сервере**, многоязычная нагрузка для редактора |
| `/api/certificates` | мои сертификаты, PDF, **публичная проверка по номеру** |
| `/api/reviews`, `/api/wishlist`, `/api/gradebook`, `/api/analytics` | отзывы, избранное, ведомость, аналитика |

### Как устроена безопасность

- Пароли — хеш ASP.NET Identity, в базе открытого текста нет.
- Доступ проверяется **по владению, а не только по роли**: преподаватель
  правит лишь свои курсы, студент видит лишь свои сертификаты.
- **Правильные ответы теста клиенту не отдаются** — в ответе API у всех
  вариантов `isCorrect: null`. Балл считает только сервер.
- Содержимое урока — HTML от преподавателя, поэтому перед вставкой в страницу
  оно проходит очистку по белому списку (`js/sanitize.js`).
- **Восстановление пароля никогда не подтверждает, зарегистрирован ли
  email.** И «email существует», и «email не существует» возвращают один
  и тот же ответ 200 — тот же принцип, что уже применяется в общем сообщении
  «неверный email или пароль» при входе.
- **Загруженные аватары проверяются на сервере**: список разрешённых
  расширений (jpg/png/webp/gif), лимит 3 МБ, старый файл удаляется при
  замене новым — «осиротевшие» файлы не копятся.

## Решения, которые стоит объяснить

**Частичный балл за тест не начисляется.** Вопрос засчитывается только при
точном совпадении множеств выбранного и правильного: ни лишнего варианта,
ни пропущенного. Это упрощение, принятое сознательно.

**Прогресс считается только по опубликованным урокам.** Черновик преподавателя
не должен занижать процент студенту — он его даже не видит.

**Сертификат нельзя запросить.** Эндпоинта «выдай мне сертификат» не существует.
Сервер выдаёт его сам, когда одновременно выполнены два условия: 100 % уроков
и все тесты курса сданы. Проверка идемпотентна — сертификат создаётся однажды.

**Смена языка не перезагружает страницу.** Интерфейс перерисовывается на месте,
а содержимое курсов запрашивается заново с новым `?lang=` — это разные механизмы.

**Демо-тесты — только на английском, и это осознанно.** Добавление таблиц
переводов к тестам не потребовало переписывать содержимое 13 тестов сразу
на трёх языках — цепочка отката `TranslationResolver` означает, что тест
только со строкой `EN` всё равно корректно откроется у студента с
азербайджанским или русским интерфейсом. AZ/RU-переводы можно добавить
позже для конкретного теста через конструктор преподавателя, не трогая
схему базы.

**Явные вызовы `DbSet.Update()` убраны из мест, где обновляются переводы.**
Вызов `Update()` для сущности, уже отслеживаемой тем же `DbContext`,
обходит весь граф связанных объектов и помечает каждую достижимую строку
как «изменённую» — включая только что созданные строки переводов,
добавленные в коллекцию через `Add()`, у которых Id уже не пустой
(`BaseEntity` присваивает `Guid` в момент создания объекта). EF в ответ
генерирует `UPDATE` для строки, которой ещё не существует, находит ноль
совпадений и падает с `DbUpdateConcurrencyException`. Исправление
двойное: убрать лишний вызов `Update()` (изменения отслеживаемой сущности
EF подхватывает и так) и явно выставлять `Id = Guid.Empty` у новых строк
переводов — тогда собственная эвристика EF «это точно новая запись»
срабатывает правильно.

## Что осталось за рамками

Честный список — эти вещи в проекте не сделаны:

- **Уведомления есть на сервере, но не в интерфейсе.** `NotificationsController`
  работает, события «курс завершён» и «результат теста» создаются, но экрана
  для них нет.
- **Номера сертификатов идут подряд** (`LMS-2026-000001`, `-000002`). Проверка
  публичная и без ограничения частоты запросов, поэтому перебором можно
  выгрузить список выпускников. Лечится ограничением частоты.
- **Оплата не реализована.** У курсов есть цена, но запись бесплатна.
- **В `.csproj` остались неиспользуемые пакеты** — Stripe, Twilio, Quartz,
  драйвер PostgreSQL, Playwright, Serilog. В коде они не встречаются ни разу.
- **Загрузка файлов есть только для аватара.** Обложки курсов и материалы
  уроков по-прежнему задаются ссылками — полноценная загрузка и хранение
  файлов для них осталась за рамками этого этапа.
- **Интерфейса для перевода тестов у преподавателя пока по сути «сырой».**
  API и база данных полностью поддерживают многоязычные тесты, и конструктор
  теста у преподавателя умеет создавать/редактировать вопросы на всех трёх
  языках — но все 13 демо-тестов из seed-данных идут только на английском
